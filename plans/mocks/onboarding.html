Welcome to Relay

Run a repeatable AI review-to-patch workflow on your code, with visible spending and your approval before any patch is drafted.

Stored on this computer

  • Projects, runs, step checkpoints and artifacts
  • Approved project memory and its revision history
  • The usage ledger tracked by Relay
  • API keys, in your OS credential store (never plaintext)

Processed remotely

  • Only the context you select: goal, diff or files, approved memory
  • Sent only to model providers you connect and allow per project
  • Nothing is sent until you start a run
  • Local storage does not make remote processing private or offline

In this preview Relay never modifies your project files. Results are proposed patches you export.

More templatesAdditional templates and structural editing come in a later release. You can edit prompts, profiles and limits of this template in Workflows.

Steps in this template

  1. Read context · builds an immutable manifest of the selected files and memory
  2. Review input · Reviewer role · findings with severity and file references
  3. Plan a fix · Planner role · ordered steps and proposed file scope
  4. Approve plan · you · approval is tied to this plan and context snapshot
  5. Produce patch · Implementer role · proposed patch artifact, no source writes
  6. Review patch · Patch reviewer role · accept, request a bounded revision, or mark incomplete
