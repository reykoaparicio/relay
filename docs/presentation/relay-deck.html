The problem

AI coding help is fast.
It is not yet trustworthy.

  • Costs are invisible until the provider bill arrives.
  • Nobody is sure which files or secrets were sent.
  • Changes land without a plan anyone approved.
What Relay is

A control layer between
your code and your AI provider.

A desktop app that runs a repeatable review-to-patch workflow, with visible spending and your approval before any patch is drafted.

In the app

Everything that needs you, on one screen.

The project overview: a run waiting for approval, spending so far, and the run limits.

How a run works

Five steps. You hold the key one.

Each step can use a different model and provider.

01
Review
A model reads the files you chose and lists findings.
02
Plan
A second model proposes what to change, and why.
03
You approve
Approve, ask for a revision, or reject. Nothing else happens first.
04
Patch
A model drafts the code change the plan allows.
05
Verify
A reviewer model checks the patch against the plan.
In the app

You approve the plan before any code is written.

Each step of the plan names the finding it fixes, the files it may change and its sources.

Safe by design

Relay never edits
your project files.

You get a report and a proposed patch. You review it and apply it yourself.

Cost you can see

Every call is checked before it is sent.

Relay reserves the most a call could cost and refuses any call that would go over your budget.

Budgets
Per run and per project per month. Raise them in place when a run pauses.
Honest numbers
Exact costs when known; otherwise shown as ~$0.06 (estimated), never “unknown”.
No surprise retries
A request that may have been charged is never re-sent without you.

Project memory

It learns your project's rules — only with your approval.

  • Runs suggest new rules; nothing is added automatically.
  • Every rule has a source, a history and a review date.
