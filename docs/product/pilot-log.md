# Pilot log (spec §20.2)

Three participants complete the same narrow task with Relay, using their permitted code or the sample repository. Offer each a second session a week later. **Record whether they come back and what they choose to use it for.** A compliment is not repeated use.

Rules: use a pseudonym only, and no confidential code or names. Record friction as observed, not as interpreted. "Returned" means they actually came back for the second session on their own task, not that they said they would.
